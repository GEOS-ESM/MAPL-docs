mapl3g_MaxMin — Global Max/Min of Arrays

This module implements functions for calculating/printing out the global min/max of fortran arrays. Derived from GEOS-4 pmaxmin() functions. The macros here are intended to simplify the process of accessing the per-gc private state via ESMF.
