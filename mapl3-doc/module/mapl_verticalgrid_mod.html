VerticalGrid

Get the primary vertical coordinate name for conservative regridding

@return The primary coordinate name (e.g., “pressure” or “height”) Empty string if not set Set the primary vertical coordinate name for conservative regridding

This identifies which coordinate should be used for normalization: - “pressure” → use DELP for mass-weighted regridding - “height” → use DZ for height-weighted regridding
